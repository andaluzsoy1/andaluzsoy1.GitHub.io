2.- Introducción del productoEste es un lector de códigos de automóviles, que admite nueve protocolos estándar de OBD II/EOBD. Plug and play, puede leer rápidamente la información de fallos del automóvil y los parámetros del vehículo, es una función más completa del instrumento de diagnóstico de fallos. Lea atentamente el manual del producto antes de usar este producto, gracias.

3.- Asuntos que requieren atención

1.- No utilice limpiadores abrasivos para limpiar este producto.

2.- No permita que este producto se caliente o se acerque a la fuente del fuego.

3.- No exponga este producto a la luz solar directa durante mucho tiempo.

4.- No intente desmontar este producto para realizar modificaciones, ya que no contiene ningún componente de mantenimiento.

5.- No utilice este producto en la habitación.

6.- Si no planea usar este producto durante mucho tiempo, guárdelo en un ambiente seco para evitar temperaturas extremas y polvo.

4.- Apariencia del producto e introducción de teclas de función.

Funciones principales

- Admite nueve protocolos estándar de OBD II/EOBD.

- Soporte de batería de coche voltaje prueba.

- Admite la lectura, borra el código de fallo del vehículo, lee el flujo de datos, congela la información del cuadro, verifica el estado de MIL, lee la información del vehículo, prueba del sensor de oxígeno, prueba del sistema de evaporación de combustible (modo 8).

- Admite consulta de información de código de error.

- Admite la función de reproducción de flujo de datos, view/Eliminar código de fallo, flujo de datos e información de cuadro congelado.

- Admite ocho idiomas inglés, alemán, italiano, holandés, francés, español, chino, ruso.

 

6.- Instrucciones de funcionamiento del producto

Cuando necesite inspeccionar un automóvil, conecte directamente este producto al conector OBD del automóvil para iniciar la inspección.

Introducción al menú de página

1.- Menú de inspección del coche.
Después de conectar el vehículo, vaya a la página de inicio, seleccione el menú "OBD/EOBD", presione el botón OK para ingresar a la página de función de prueba, este menú tiene 9 funciones de prueba, puede usar las teclas de función arriba/abajo para cambiar de página .

2.- Leer flujo de datos
Después de conectarse al vehículo, vaya a la página de inicio, seleccione el menú "Flujo de datos" y presione OK para ingresar el flujo de datos view pag

3.- Consulta de código de fallo
Después de conectar el vehículo, vaya a la página de inicio, seleccione el menú "DTC Lib", presione el botón OK para ingresar a la página de consulta del código de fallo, apoye la consulta del código de fallo del vehículo y explique el motivo.

4.- Estado listo I / M
Después de conectar el vehículo, ingrese a la página de inicio, seleccione el menú "I/M" y presione el botón OK para ingresar a la página de configuración. Este menú tiene 2 funciones y puede usar las teclas de función arriba/abajo para pasar las páginas.

5.- Voltagy prueba
Después de conectar el vehículo, vaya a la página de inicio, seleccione el botón “Voltage”, presione el botón OK para ingresar al menú vol.tage página de prueba, y verifique el voltage valor.

6.- Configuraciones del producto
Después de conectar el vehículo, vaya a la página de inicio, seleccione el menú "Configuración" y presione el botón OK para ingresar a la página de configuración. Este menú tiene 2 funciones de configuración y puede usar las teclas de función arriba/abajo para pasar las páginas.
